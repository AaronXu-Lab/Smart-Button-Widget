# Smart Button Widget (Easy Script)

这是一个已发布的 Figma/FigJam 小组件（Widget），旨在为设计画布提供智能交互按钮，支持运行便捷脚本，以大幅提升日常设计与流程管理效率。

## 功能特点

- **智能按钮**：在画布上创建可定制的交互按钮。
- **脚本执行**：通过关联 UI 与后台逻辑，轻松触发一系列画布操作。

## 快速上手

1. 下载或克隆本仓库。
2. 在终端运行 `npm install`。
3. 运行编译命令（如 `npm run dev`）生成 `dist/code.js`。
4. 在 Figma 中导入 `manifest.json`，即可在画布中添加并使用该小组件。
